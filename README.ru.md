Led Lights — форк плагина [Colores](https://github.com/Hooandee/decky-colores) от
[Hooandee](https://github.com/Hooandee). Плагин определяет консоль при запуске и
показывает только то, что она действительно умеет: без списка моделей и правки
конфигов. Открывается из меню быстрого доступа Steam.

## Что добавлено в этом форке

- **Амбилайт по краям экрана.** В апстриме каждая половина экрана освещает кольцо
  своего стика. Здесь добавлена вторая раскладка — **«Края экрана»**: каждый LED
  берёт цвет ближайшего края картинки, как амбилайт у телевизора. Четыре зоны
  левого стика читают левый край, четыре зоны правого — правый, зона ABXY — нижний.
  Раскладка переключается в панели: «Стики» (как в апстриме) или «Края экрана».
- **Амбилайт в Desktop Mode.** Апстрим захватывает экран только в Game Mode через
  PipeWire из gamescope. Led Lights сохраняет этот путь и добавляет захват рабочего
  стола: активный экран читается через D-Bus API KWin `ScreenShot2` с теми же
  настройками сочности, сглаживания и частоты. Без диалогов порталов и лишних прав.
- **Языки.** Английский язык по умолчанию, добавлен полный русский перевод.
  Автообновление отключено: у форка нет своего релизного канала.
- **CI и упаковка.** GitHub Actions прогоняют тесты бэкенда и фронтенда, собирают
  бандл и готовый ZIP; тег `v*` публикует релиз.

## Поддерживаемые устройства

| Марка | Модели | Детали |
| --- | --- | --- |
| MSI | Claw, Claw A8, Claw 8 AI+ | 9 зон: 4 вокруг правого стика, 4 вокруг левого, 1 на ABXY |
| ASUS ROG | Ally, Ally X, Xbox Ally, Xbox Ally X | 4 зоны RGB на кольцах стиков |
| Lenovo Legion | Go, Go 2, Go S | Цвет на каждый контроллер, кнопка переподключения |
| AYN | Thor, Odin 3 (Linux, Armada OS) | 8 зон на кольцах стиков |

Раскладка по краям и захват рабочего стола разработаны и проверены на
**MSI Claw A8 (BZ2EM)**, 9 зон. На устройствах с одной общей зоной плагин
показывает один усреднённый цвет.

Для остальных консолей Led Lights всё равно пытается управлять теми LED, которые
видит система, и помечает такие функции как экспериментальные.

## Что можно делать

- **Однотонный цвет** с выбором оттенка и насыщенности.
- **Яркость** на устройствах, где она доступна.
- **Градиенты** с редактором по зонам, пресетами (Закат, Океан, Аврора, Лава,
  Галактика и другие), авто-палитрой, кнопкой «Удиви меня» и сохранением своих.
- **Эффекты**: дыхание, радуга, волна, цикл и спираль, в том числе на своём градиенте.
- **Амбилайт**, следящий за экраном, с сочностью, сглаживанием и частотой захвата.
- **Режимы датчиков, часов и звука**: заряд, температура, загрузка, оттенок по
  времени суток и VU-индикатор.
- **Языки**: английский (по умолчанию), испанский, русский, итальянский, немецкий,
  бразильский португальский и французский; переключаются в настройках.

## Откуда берётся картинка

| Сессия | Источник | Хелпер |
| --- | --- | --- |
| Game Mode | нода gamescope в PipeWire (`pw-dump` / `wpctl`) | `py_modules/pw_capture.py` (при отсутствии libpipewire — GStreamer) |
| Desktop Mode (KDE) | KWin `org.kde.KWin.ScreenShot2` → `CaptureActiveScreen` | `py_modules/kwin_capture.py` |

Источник выбирается автоматически: если запущен композитор gamescope — Game Mode,
иначе захватывается рабочий стол. Кадр уменьшается до 32×18 в host-питоне (numpy,
если установлен) и сглаживается в процессе плагина. Для рабочего стола частота
ограничена 15 fps; на Claw A8 это около 8 % одного ядра.

## Установка

1. Скачайте `LedLights-<версия>.zip` из [последнего релиза](https://github.com/mops1k/decky-led-lights/releases/latest).
2. В Decky включите режим разработчика и выберите **Install Plugin from ZIP**.

Плагину нужны права root для записи в LED; Decky запросит их при установке.

> **Не ставьте Led Lights рядом с Colores.** Оба плагина управляют одними и теми же
> HID-зонами и будут перебивать друг друга. Сначала удалите или отключите второй.

## Как пользоваться

1. Откройте меню быстрого доступа и выберите **Led Lights**.
2. Перейдите на вкладку режима **Ambilight**.
3. Выберите раскладку: **«Стики»** (как в апстриме) или **«Края экрана»** (как у ТВ).
4. Настройте сочность, сглаживание и частоту захвата. Цвет LED повторяет ближайший
   край экрана: красная стена слева подсветит кольцо левого стика красным.

## Разработка

```bash
pnpm install && pnpm build     # собрать фронтенд в dist/index.js
pnpm typecheck                 # tsc --noEmit
pnpm test:fe                   # vitest
python -m pytest               # тесты бэкенда
python3 scripts/package.py     # собрать packages/LedLights-<версия>.zip
```

Установить локально собранный ZIP можно из меню разработчика Decky или из
терминала под root:

```bash
pkexec bash scripts/install.sh packages/LedLights-<версия>.zip
systemctl restart plugin_loader
```

## CI

`.github/workflows/ci.yml` запускается на каждый push и pull request:

- **backend**: `ruff check` и `pytest` на Python 3.11;
- **frontend**: `pnpm typecheck`, тесты содержимого переводов, `vitest` и сборка,
  на Node 20 и 22 с кешем pnpm;
- **package**: сборка ZIP и публикация его как артефакта workflow.

`.github/workflows/release.yml` срабатывает на теги `v*`: собирает ZIP, генерирует
заметки к релизу и прикрепляет файл.

## Известные ограничения

- Захват рабочего стола работает через KWin (Plasma). Для GNOME/Sway пути пока нет.
- Захват Game Mode наследует PipeWire-путь апстрима и на этой сборке ещё не
  перепроверялся.
- Lenovo Legion Go: контроллеры могут терять канал цвета после сна (кнопка
  **Переподключить контроллеры**), а прошивка допускает только один цвет на
  контроллер; «спираль» — собственный эффект прошивки.
- Устройства вне таблицы работают в экспериментальном режиме, пока их не откалибруют.
